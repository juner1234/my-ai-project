# 《暖暖的日常》EP01｜我的妈妈

**最终制作需求文档（待第一、二阶段确认后执行制作）**  
目标时长：约 50 秒（以自然配音时长为准，可适当延长）｜16:9 横屏｜24 fps｜Remotion + 现有 Spine

## 01 项目目标与边界

制作治愈、开心、俏皮的手绘绘本短视频：**暖暖的日常手账感 + 唯美童话绘本感**。画面丰富但不杂乱，动画轻缓、温柔、有故事感，而非素材拼接、字幕 PPT 或特效展示。

**硬性限制：**
- 只使用现有暖暖**正面 Spine** 骨骼及人物资源；不重绘、不改外观、不制作背面动作，保留已修复的睫毛显示及跟随效果。
- 妈妈全程不出镜：不得出现她的脸、手、身体、影子或其他具象形象；只通过衣柜、衣服、场景和暖暖旁白体现她的存在。
- 不覆盖 `AnimeWorldTest`，另建独立 EP01 Composition；不擅自重构现有播放器或破坏可用版本。
- 不使用粒子爆发、炫光、强闪、3D、写实、复杂转场、快速推拉、复杂镜头旋转或大量爆炸式动态。
- 不调用付费接口；外部素材必须确认许可、保存来源和必要署名信息。

## 02 成片规格

| 项目 | 要求 |
|---|---|

| 画幅/帧率 | 16:9 横屏，24 fps |
| 风格 | 治愈手账、唯美童话、少女手绘绘本 |
| 背景 | 奶白色纸张纹理，轻微纸页质感和适度纸页晃动 |
| 主色 | 奶油粉、奶油黄、浅木棕、米白、淡奶蓝、浅玫瑰色，少量浅灰蓝 |
| 人物 | 现有暖暖正面 Spine 骨骼动画 |
| 字幕 | 必须有，逐句与实际配音对齐，不遮挡脸及主体动作 |
| 配音 | 免费 TTS 生成，独立音轨导入 Remotion |
| 音乐/音效 | 一首贯穿全片的 BGM，适量定点音效，旁白优先 |

## 03 最终旁白文案（不得擅自改写）

嗨，我叫暖暖。  
我有一个超爱我的妈妈。

妈妈最大爱好，就是给我挑新衣服。

每天早上，她打开衣柜，对着裙子陷入沉思。  
穿这件？还是这件？

有时候我偷偷想：  
妈妈哪里是养女儿，她分明在玩奇迹暖暖。

妈妈总觉得衣柜还差一件。  
昨天的小裙子，今天就失宠。  
一件两件三件……衣柜快要关不上。

我歪头问妈妈：我到底有多少裙子呀？

妈妈笑着说：不多，也就亿点点。

【视觉高潮：衣柜弹开，裙子和蝴蝶结涌出】

暖暖看着满地裙子，轻轻摇了摇头，软软笑着说：  
好吧好吧，反正妈妈，是最爱我的。

> 方括号内容为画面提示，不读出。妈妈的台词由暖暖旁白转述，妈妈不单独出镜；是否采用第二声线须先征得确认。

## 04 配音与字幕

- 使用免费 TTS；优先软萌、温柔、小女孩感、治愈、略俏皮的声线；不要求训练语音模型。
- 语速轻快但不急促，先生成试听，确认后导出清晰音频，作为 Remotion 独立旁白轨。
- **根据实际音频时间轴**再调整镜头、字幕和音效；不为硬凑 50 秒牺牲自然停顿。
- BGM 音量低于旁白，旁白期间压低 BGM；音效不盖过人声。
- 字幕使用圆润手写体或温柔绘本字体，颜色为浅棕/奶油粉/深奶茶色；逐句分行，淡入、轻微弹入或轻随纸页晃动；不遮挡暖暖脸部或主体动作。字体亦需确认使用许可。

## 05 目标分镜（时间为初稿，以实际配音微调）

| 时间 | 画面内容与镜头 | 旁白 / 音效 | 叙事重点 |
|---|---|---|---|
| 0–5s | 奶白纸张背景，手绘绘本缓缓翻开；暖暖正面出现，轻微呼吸、纸页微晃；若现有骨骼支持可眨眼 | “嗨，我叫暖暖。我有一个超爱我的妈妈。”；轻柔翻页、轻 pop | 建立绘本世界 |
| 5–11s | 暖暖站在手绘卧室，旁边衣柜半开；镜头慢推，柜中浅色裙子；少量贴纸星星 | “妈妈最大爱好，就是给我挑新衣服。”；轻柜门声 | 交代妈妈爱挑衣服 |
| 11–18s | 衣柜内部特写，裙子轮流切换；暖暖在侧边看；手绘便签、箭头、小爱心 | “每天早上，她打开衣柜，对着裙子陷入沉思。穿这件？还是这件？”；布料轻擦、小疑问音 | 妈妈不出镜仍有存在感 |
| 18–25s | 手账构图，暖暖在文字和小插画间；小裙子、蝴蝶结、虚线框、手写标签 | “有时候我偷偷想：妈妈哪里是养女儿，她分明在玩奇迹暖暖。”；俏皮轻 pop | 内心吐槽，节奏转可爱 |
| 25–32s | 延续同一衣柜，衣服一批批叠加，柜门渐渐鼓起；暖暖正面反应仅用现有支持动作 | “妈妈总觉得衣柜还差一件。昨天的小裙子，今天就失宠。一件两件三件……衣柜快要关不上。”；轻贴纸/衣服叠加声、克制滑稽鼓点 | 喜剧铺垫 |
| 32–37s | 暖暖正面轻歪头提问，旁边手绘问号、便签出现 | “我歪头问妈妈：我到底有多少裙子呀？”；软萌疑问音 | 对话承接 |
| 37–42s | 衣柜特写，衣服满到溢出；小皇冠、花朵、蝴蝶结形成手账拼贴 | “妈妈笑着说：不多，也就亿点点。”；轻铃/小 pop | 笑点前停顿 |
| 42–47s | **唯一高动态高潮**：柜门“砰”地弹开，裙子、蝴蝶结、丝带涌出并铺满画面；人物仍为正面，不做未支持的表情 | 柜门弹开、布料涌动、俏皮喜剧音效 | “亿点点”视觉兑现 |
| 47–50s（可延长） | 满地裙子中暖暖轻轻摇头（若骨骼支持），画面柔和，少量爱心与星星；绘本缓缓合上 | “好吧好吧，反正妈妈，是最爱我的。”；合页声、温柔收尾音 | 温暖情绪落点 |

**场景连续性：** 衣柜出现 → 打开 → 挑选 → 越塞越满 → 柜门鼓起 → “亿点点”涌出。不要每句旁白都机械换一张互不关联的画面。

## 06 画面、美术与素材统一规范

- 以**现有暖暖角色画风为基准**，先分析人物的线条粗细、轮廓柔和度、上色方式、比例与色彩，再定统一美术规范。
- 优先寻找**同一作者、同一系列**的合法免费手绘素材包；不可将不同网站的“可爱素材”直接混拼。素材不足时按同一色板和线条规范使用 SVG/CSS 补绘。
- 可用元素：手绘衣柜、裙子、卧室、星星、爱心、蝴蝶结、花朵、便签、箭头、虚线框、波浪线、小皇冠、丝带、手写标签、纸胶带、局部漫画分格、手账拼贴插图。
- 组合形式要多样但自然：人物居中与周围插画、人物偏侧与场景、全屏绘本、局部特写、手账排版、偶尔漫画分格；保持留白与呼吸感，装饰不抢暖暖、衣柜和故事主体。
- 贴纸必须有手绘感，不用写实贴纸；文字可与插画互动（问句旁问号、裙子旁小标签）。纸张纹理贯穿全片，纸页晃动须轻微。
- 禁止混搭 3D、写实、扁平矢量、厚涂、赛璐璐、强反光、金属、霓虹等不一致画风。
- 避免大面积黑色、深蓝、荧光色、高饱和红橙和强对比冷色。
- 找到素材后需实际核验下载可用性、商用许可及署名要求，提交**名称、用途、作者、来源、许可、是否下载**的清单；未找到的不可报告为已完成。

## 07 动画规则与 Spine 能力边界

**允许：** 绘本翻页、纸张轻微晃动、元素淡入淡出、手写字浮现、贴纸轻弹入、镜头慢推慢移、裙子轻柔滑动、衣柜轻震后弹开。暖暖仅使用当前正面 Spine 已支持的呼吸、歪头、摇头等动作；眨眼、微笑、睁大眼睛等须**先验证现有骨骼及素材确实支持**，不支持则调整分镜表现，不擅自改人物、补画表情或声称已经实现。

**禁止：** 粒子爆发、强闪、炫光、快速推拉、花哨转场、复杂旋转、大量爆炸式动态、改变暖暖外观、制作背面动作。高潮可由**衣柜及衣物道具**承担动态，不要求人物做新动作。

所有画面、人物动作、字幕、音乐、音效均纳入 Remotion 时间轴，确保 Studio 预览与 MP4 渲染一致。

## 08 音效设计

| 情节 | 音效 | 说明 |
|---|---|---|
| 开场 | 轻柔翻页声 | 建立绘本感 |
| 暖暖出现 | 轻 pop | 可爱入场 |
| 衣柜打开 | 木质柜门轻响 | 生活化 |
| 裙子切换 | 布料轻擦 | 模拟挑衣服 |
| 思考停顿 | 小疑问音 | 俏皮手账感 |
| 衣服增加 | 轻 pop / 贴纸声 | 每增加一批触发一次，不逐件滥用 |
| “亿点点” | 轻铃 / 小 pop | 笑点提示 |
| 衣柜弹开 | 柜门砰声 + 布料涌动 | 唯一高动态高潮 |
| 贴纸出现 | 轻弹入声 | 适量点缀 |
| 结尾 | 绘本合页声 + 温柔轻音 | 治愈收束 |

音效须免费可商用、来源和许可可核验；音量克制、严格与动作同步、不刺耳、不盖旁白。优先纸张、布料、木质、木琴、轻铃和柔和 pop 类声音。

## 09 背景音乐

- 方向：Cozy / Playful / Whimsical / Cute，治愈、童话、手账感；可考虑轻柔钢琴、木琴、尤克里里、轻铃、软萌八音盒。
- 一首音乐贯穿全片，不频繁切换；旁白期间降低音量；“亿点点”高潮可轻微增强但不激烈，结尾随绘本合上自然收束。
- 主动寻找免费可商用的真实曲目，核对来源、作者、具体授权和署名条件；若环境支持则试听比较，不可仅凭文件名选择。禁止使用来源不明、无法核实许可的资源。

## 10 技术、性能与交付

- 使用现有 `AnimeWorld` + Remotion + Spine；另建 EP01 Composition，资源独立存放，不覆盖 `AnimeWorldTest`。
- 除暖暖人物外，场景可由 Remotion/SVG/CSS 绘制或使用风格统一、许可合规的手绘素材。
- 免费 TTS 音频、BGM、音效作为独立轨道导入，字幕按实际音频逐句同步。
- Mac 8GB 内存：避免过多高分辨率素材同时加载，先做低分辨率预览，不直接进行最终高分辨率渲染。
- 不擅自重构现有播放器，不破坏当前可用版本；重大、原因不明或反复出现的错误先汇报证据，等待确认，不盲目反复尝试。

## 11 分阶段执行与确认点（必须遵守）

**阶段一｜只读核查与策划**：核验现有 Spine 能力和睫毛状态；分析暖暖画风，提出统一美术规范；寻找并核验免费手绘素材、BGM、音效、TTS 候选，提交来源/作者/许可/署名/可用性清单。说明任何缺失或风险。**先展示方案，等待我确认。**

**阶段二｜分镜与声音定稿**：提交镜头构图、连续场景设计、配音试听（如生成音频需先说明操作和产物位置）、音乐候选及音效安排；根据实际旁白修正时间轴。**再次等待我确认。**

**阶段三｜正式制作**：仅在确认后开发完整 Remotion EP01，交付含人物、手绘场景、字幕、配音、BGM 和音效的低分辨率完整预览，以及素材授权清单。预览确认前**不做最终高分辨率渲染**。

**完成标准：** 观众感觉暖暖生活在同一个温暖、可爱、有趣的手绘世界里；前段温柔介绍，中段俏皮挑衣服，末段“亿点点”喜剧高潮后回归妈妈对暖暖的爱。画面与声音统一，不能只是技术展示。
