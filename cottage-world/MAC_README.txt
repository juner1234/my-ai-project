苔光别墅 · Mac 探索版 0.1.0

适用：Apple Silicon（M1/M2/M3/M4 等），macOS 11 及以上。
解压 ZIP 后双击“苔光别墅.app”，不需要安装 Godot 或 Blender。

应用未获 Apple Developer ID 签名及公证，只有 ad-hoc 签名。
若系统拦截：先尝试打开，再到“系统设置 → 隐私与安全性”选择“仍要打开”。
不需要关闭系统安全保护，也不需要终端命令。

WASD 移动，鼠标转向，靠近门按 E，空格跳跃。
数字 1 / 2 / 3 切换蓝天、黄昏和夜景。
Tab 布置家具，Esc 暂停、调整画质、返回入口、保存并退出。
默认“均衡”；如果卡顿，切到“流畅”。
家具和画质设置保存在 ~/Library/Application Support/MosslightVilla/。
